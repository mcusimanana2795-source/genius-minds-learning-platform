# Genius Minds Learning Platform

A responsive starter learning platform for Genius Minds Tutoring.

## Publish
This repository is configured for GitHub Pages using the workflow in `.github/workflows/deploy.yml`. In GitHub, open **Settings → Pages** and ensure **Build and deployment → Source** is set to **GitHub Actions** if it is not already selected. The workflow will publish the site after a successful run.

## Included in this starter version
- Learner dashboard and subject library
- Sample topics for Grade 3, Grade 4, Grade 5 and Grade 7
- Explanations, examples and browser voice narration
- Independent multiple-choice topic assessments with automatic marking
- Progress tracking saved in the current browser
- CSV progress export
- Basic tutor overview

## Important limitations
This is an initial front-end MVP, not a secure production learning management system. Progress is saved in local browser storage on the current device only. It does not yet provide secure learner accounts, cloud synchronisation, a shared tutor database, conversational AI tutoring, or a fully verified CAPS/ATP curriculum. Sample content must be checked against the current relevant ATP before formal use. Browser voice narration uses the device's built-in text-to-speech voices.

Do not enter real learner personal information into this public demonstration site.
